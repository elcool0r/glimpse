# Code of Conduct

## Our standard

We want Glimpse to be a welcoming, practical, and respectful project. All
participants are expected to:

- be considerate and professional;
- discuss ideas and code, not people;
- welcome good-faith disagreement and constructive feedback;
- respect different backgrounds, experience levels, and perspectives; and
- take responsibility for mistakes and help repair their impact.

Unacceptable behaviour includes harassment, discrimination, personal attacks,
threats, sexualised language or attention, publishing private information, and
any other conduct that would reasonably make participation unsafe or unwelcome.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, and
pull requests that violate this code. They may also temporarily or permanently
restrict participation when necessary to protect the community.

Report concerns privately to the maintainers through the contact method listed
in the repository owner’s GitHub profile. Please do not create a public issue
for sensitive reports. Reports will be handled as confidentially as practical.

This code of conduct is adapted from the Contributor Covenant and applies to
all project spaces, including issues, pull requests, discussions, and reviews.
