| Disk space free, inodes exhausted                                | Small-file workload                                                     | Apparently contradictory disk metrics                                     | Covered — `filesystem-inodes-<mount>` is fully independent of the used-space check, tested. |
| `df` and `du` disagree                                           | Deleted-open files, mounts or reserved space                            | Requires correlating filesystem/process information                       | Covered — `deleted-files-open` directly targets this case, tested. |
| Ping fails, HTTPS works                                          | ICMP filtering                                                          | Prevents false "Internet down" diagnosis                                  | Covered — independent ICMP vs. HTTP(S) checks, tested. |
| DNS works, application resolution fails                          | NSS/hosts/resolved problem                                              | DNS packet test alone produces a false green result                       | Partial — only the narrow stub-resolver-plus-failed-unit case is covered (`dns-stub-resolver-failed`); general NSS/hosts breakage isn't checked. |
| Service active, port open, request fails                         | Application deadlock/upstream failure                                   | Multiple basic checks are green despite outage                            | Skipped — requires an application-level request probe, out of scope. |
| Host RAM free, service OOM-killed                                | cgroup memory limit                                                     | Requires understanding local versus global resource limits                | Covered — `cgroup-oom-kill`, tested. |
| Load high, CPU idle                                              | I/O-blocked tasks                                                       | Requires interpreting Linux load correctly rather than thresholding it    | Partial — only indirectly detected via `disk-contention-<name>` when I/O also corroborates; no direct standalone finding. |
| Network healthy, application times out                           | Backend, TLS, proxy or application issue                                | Prevents blaming networking merely because symptoms involve connections   | Skipped — application-level differential diagnosis, out of scope. |
